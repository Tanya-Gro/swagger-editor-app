Review this React and TypeScript project for students. Give actionable fixes and
include concise code examples when they materially clarify the recommendation.

Check React and TypeScript best practices:

- SOLID principles and clean, focused components; flag components over 100 lines
  when extracting responsibilities would improve maintainability.
- Correct hook usage, complete dependency arrays, and no inappropriate side
  effects.
- Strict TypeScript, avoiding `any` and redundant explicit types where inference
  is clear.
- ESLint compliance and meaningful performance issues.
- Security issues, especially exposed or directly embedded API keys.
- Accessibility, semantic HTML, and modern web practices.

Check architecture:

- State-management choices, including whether Zustand or TanStack Query would
  solve an actual project need.
- Routing and error handling.
- Scalability and separation of responsibilities.

Prioritize correctness, security, and maintainability. Avoid cosmetic comments
that do not provide a concrete benefit.
